# دليل يوم المعرض وخطة الطوارئ — منصة رداء

## 1. قبل الافتتاح (ت − 72 ساعة)

1. بروفة كاملة: دعوة تجريبية → حضور (مسح + يدوي) → صرف → تقرير.
2. تشغيل **نسخ احتياطي + استرجاع تجريبي**:
   ```bash
   ./scripts/backup.sh
   ./scripts/restore-drill.sh
   ```
   القبول: تطابق أعداد الجداول بين المصدر والنسخة المستعادة.
3. طباعة بطاقات QR للمدعوين:
   - من النظام: `/api/invites/qr-cards` (صلاحية الدعوات)
   - أو رابط التصدير من شاشة الدعوات إن وُجد.
4. طباعة كشف ورقي بالمدعوين (اسم + آخر 4 من الهوية) كخطة B.

## 2. أدوار التشغيل (بطاقة صفحة واحدة)

| الدور | الشاشة الرئيسية | ممنوع |
|---|---|---|
| استقبال | الحضور | الصرف / الإعدادات |
| تسجيل | المستفيدون + الدعوات | الصرف |
| توزيع | صرف القطع | تعديل الإعدادات |
| مخزون | المخزون | الدعوات |
| تقارير | التقارير / الاستبيان | تصدير الهوية الكاملة |
| مدير | الكل + المعارض + المستخدمون | — |

## 3. أعطال شائعة

| العَرَض | الإجراء |
|---|---|
| الكاميرا لا تعمل | البحث اليدوي بالهوية فوراً |
| «تم الحضور مسبقاً» | لا تعِد المسح — تحقق من الشاشة |
| «كمية غير كافية» | حوّل لمخزون / صنف بديل |
| انقطاع الشبكة | فعّل الكشف الورقي + سجّل يدوياً ثم أدخل لاحقاً إن أمكن |
| لا معرض نشط | المدير يفعّل المعرض من «المعارض» |

## 4. سلسلة الاتصال

1. مشرف القاعة → 2) مدير النظام → 3) دعم تقني الجمعية.

## 5. النسخ الاحتياطي أثناء المعرض

- نسخة قبل الافتتاح، ونسخة منتصف اليوم، ونسخة عند الإغلاق.
- أمر النسخ: `./scripts/backup.sh`
- الاسترجاع لا يُجرى على قاعدة الإنتاج إلا بأمر المدير وبعد عزل النسخة الحالية.
