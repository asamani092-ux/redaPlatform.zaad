# سياسة الاحتفاظ وحذف البيانات الشخصية — منصة معرض رداء

**الجهة:** جمعية الزاد للخدمات الإنسانية  
**النطاق:** بيانات المستفيدين (الاسم، رقم الهوية، الجوال، الجمعية، الحضور، الصرف) وسجلات التشغيل.

## 1. مبادئ

1. تُجمع البيانات لغرض تشغيل المعرض وتوثيق الاستحقاق والتدقيق فقط.
2. الوصول للهوية والجوال الكاملين عند التصدير مقصور على **مدير النظام** (فرض من الخادم).
3. لا تُكتب أرقام الهوية أو الجوال في سجلات التطبيق النصية (stdout/logging).
4. عند النشر/التحديث: لا تُحذف قاعدة البيانات ولا مجلد `/data` (نسخ ومرفقات) — انظر `docs/DEPLOY.md`.

## 2. مدد الاحتفاظ المقترحة

| الفئة | المدة | ملاحظات |
|---|---|---|
| مستفيدون + دعوات + حضور + صرف | حتى **12 شهراً** بعد انتهاء المعرض | أو وفق قرار إداري موثّق أقصر |
| سجل التدقيق | **24 شهراً** | لأغراض المساءلة والمراجعة |
| رسائل صادرة (stub/سجل) | **6 أشهر** | |
| نسخ احتياطية | دورة **30 يوماً** دوّارة | مع اختبار استرجاع قبل كل معرض |

## 3. الحذف

1. بعد انتهاء مدة الاحتفاظ: حذف أو إخفاء هوية/جوال من جداول المستفيدين مع الإبقاء على مجاميع إحصائية بلا معرف شخصي إن لزم.
2. الحذف يتم بأمر إداري موثّق (من/متى/نطاق المعرض) ويُسجَّل في التدقيق.
3. لا يُصدَّر ملف يحوي هوية/جوال لغير المدير.
